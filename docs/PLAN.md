# Video Log — Separate Video Tracking from Task Resources

## Problem

Videos get re-evaluated because there's no central record of "I've already seen this URL." The current hack: marking videos as `is_consumed: true` in the `resources` table even when not watched, just to trigger duplicate detection via `check-url`. This pollutes resources with dishonest data.

A skipped video is NOT a resource — it's a triage decision. Different domain concept, different table.

## Solution

New `video_log` table — every video URL ever encountered, with its verdict. The dedup layer.

- **Resources** (`resources` table) — genuine learning materials attached to tasks. **No changes.**
- **Video Log** (`video_log` table) — records every video decision. The single source of truth for "have I seen this URL?"

Future: a Telegram bot will also write to `video_log` with `source='telegram'`.

### 2.2 Add `log_video` function

Add this function after the `update_resource` function (after line 150):

```python
def log_video(data: dict):
    data.setdefault("source", "pipeline")
    data.setdefault("notes", None)
    data.setdefault("profile_used", None)
    data.setdefault("resource_id", None)
    with get_conn() as conn, conn.cursor(cursor_factory=psycopg2.extras.RealDictCursor) as cur:
        cur.execute(
            "INSERT INTO video_log (url, title, verdict, source, notes, profile_used, resource_id) "
            "VALUES (%(url)s, %(title)s, %(verdict)s, %(source)s, %(notes)s, %(profile_used)s, %(resource_id)s) "
            "ON CONFLICT (url) DO UPDATE SET "
            "verdict = EXCLUDED.verdict, notes = EXCLUDED.notes, "
            "resource_id = EXCLUDED.resource_id "
            "RETURNING id, url, title, verdict",
            data,
        )
        conn.commit()
        return cur.fetchone()
```

The `ON CONFLICT ... DO UPDATE` handles the case where a previously skipped video gets re-evaluated and filed — the verdict and resource_id get updated.

### 2.3 Replace the `check_url` function

Replace the existing `check_url` function (lines 163-176) with:

```python
def check_url(url: str):
    video_id = extract_video_id(url)
    if not video_id:
        return None
    with get_conn() as conn, conn.cursor(cursor_factory=psycopg2.extras.RealDictCursor) as cur:
        # Check video_log first (primary dedup source)
        cur.execute(
            "SELECT vl.id, vl.url, vl.title, vl.verdict, vl.notes, vl.logged_at, "
            "vl.resource_id, t.name AS task_name, p.name AS project_name "
            "FROM video_log vl "
            "LEFT JOIN resources r ON vl.resource_id = r.id "
            "LEFT JOIN tasks t ON r.task_id = t.id "
            "LEFT JOIN projects p ON t.project_id = p.id "
            "WHERE vl.url LIKE %s OR vl.url LIKE %s",
            (f"%youtube.com/watch?v={video_id}%", f"%youtu.be/{video_id}%"),
        )
        result = cur.fetchone()
        if result:
            return result

        # Fallback: check resources directly (legacy data not yet backfilled)
        cur.execute(
            "SELECT r.id, r.title, r.url, r.is_consumed, t.name AS task_name, "
            "p.name AS project_name FROM resources r "
            "JOIN tasks t ON r.task_id = t.id "
            "JOIN projects p ON t.project_id = p.id "
            "WHERE r.url LIKE %s OR r.url LIKE %s",
            (f"%youtube.com/watch?v={video_id}%", f"%youtu.be/{video_id}%"),
        )
        result = cur.fetchone()
        if result:
            result["verdict"] = "filed"  # legacy resource = filed
            result["source"] = "legacy"
        return result
```

## Architecture After Implementation

```
Video URL enters system
        │
        ▼
  check-url (video_log → fallback resources)
        │
   ┌────┴────┐
   │ Found?  │
   └────┬────┘
    YES │         NO
        ▼          ▼
  "Already      Filter analysis
   processed"        │
   (STOP)       ┌────┴────┐
                │ Verdict │
                └────┬────┘
           SKIP/     │      WATCH/
           GRAVE     │      SKIM
              ▼      │        ▼
         log-video   │   Match project/task
         verdict=    │   add-resource → get resource_id
         'skipped'   │   log-video verdict='filed'
         (STOP)      │        │
                     └────────┘
```
